# `results/` output directories — dates and the scripts behind them

Companion to `01.script_index.csv`. One row per top-level directory in
`projects/amgen/results/`: the date range of the files inside it, how many files,
and the scripts that reference it. Compiled 2026-07-31.

Scripts in **bold** were detected writing into that directory; the rest reference
it (often reading it as input). Detection is by literal path and directory-name
matching in the script source, so it is good but not exhaustive — a directory with
no script listed was most likely produced by a script now in `backup/`,
`deprecated/` or `_backup_surfaceome_pipeline_v1/`, or by one that builds its
output path entirely from variables.

Dates are file modification times. The Cell Ranger trees (`cellranger_withbam`,
`cellranger_downsampled_reseq`) were walked to depth 3 only, so their file counts
are shallow entries rather than every Cell Ranger file.
